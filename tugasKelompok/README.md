## Deskripsi Aplikasi
Aplikasi sederhana Android menggunakan Kotlin yang menampilkan:

- Halaman 1: Sejarah perkembangan Android dari tahun 2003 hingga sekarang  
- Halaman 2: Arsitektur Android (Linux Kernel, Native Libraries, Android Runtime, Application Framework, Applications)  
- Informasi device pengguna secara real-time (Model, Manufacturer, Android Version, SDK Version)  
- Navigasi antar halaman menggunakan Intent  

## Fitur Utama
- Menggunakan 2 Activity  
- Perpindahan halaman menggunakan Intent  
- Mengambil informasi perangkat menggunakan class `Build`  
- Menggunakan ScrollView untuk konten panjang  
- Tampilan container menggunakan CardView  

## Cara Menjalankan
1. Clone repository ini  
2. Buka di Android Studio  
3. Tunggu hingga Gradle Sync selesai  
4. Jalankan menggunakan Emulator atau Device  
5. Klik tombol "Lihat Arsitektur dan Info Device" untuk berpindah halaman
