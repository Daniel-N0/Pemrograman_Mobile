Nama: Daniel Noprianto

## Deskripsi Singkat
Aplikasi Android sederhana yang menampilkan sapaan berdasarkan nama yang diinput oleh pengguna.
Terdapat fitur Mode Gelap dan Mode Terang menggunakan Switch.

## Fitur
- Input Nama
- Tombol Sapa
- Validasi nama
- Mode Gelap / Terang

## Cara Menjalankan
1. Download project
2. Buka di Android Studio
3. Klik Run
4. Pilih emulator atau device
