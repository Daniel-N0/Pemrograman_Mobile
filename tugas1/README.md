## Deskripsi Singkat

Aplikasi Android sederhana yang menampilkan sapaan berdasarkan nama yang diinput oleh pengguna.  
Aplikasi ini dilengkapi dengan validasi input serta fitur Mode Gelap dan Mode Terang menggunakan Switch.

---

## Fitur Aplikasi

- Input nama pengguna
- Tombol **Sapa**
- Menampilkan teks: **Hello (nama)!**
- Validasi nama (tidak boleh kosong dan minimal 3 karakter)
- Mode Gelap / Terang

---

## Cara Menjalankan Aplikasi

### A. Melalui Android Studio

1. Download atau clone repository ini
2. Buka **Android Studio**
3. Klik **Open**
4. Pilih folder project
5. Tunggu proses Gradle Sync selesai
6. Klik tombol **Run**
7. Pilih emulator atau device
8. Aplikasi akan berjalan otomatis

---

### B. Menggunakan File APK di HP Android

1. Download file `app-debug.apk`
2. Pindahkan ke HP Android
3. Buka file APK
4. Aktifkan **Allow from this source** jika diminta
5. Klik **Install**
6. Setelah selesai, klik **Open**
